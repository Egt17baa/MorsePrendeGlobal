# Pruebas en el móvil: Etapa 2

Móvil de referencia: **Honor Magic 8 Pro** (MagicOS, Android 16).

## Instalar (solo esta vez hay que desinstalar)

1. **Desinstala la Etapa 1** (mantén pulsado el icono → Desinstalar). Cambia la clave de firma y
   Android no deja instalar encima. No se pierde nada: la Etapa 1 no guardaba progreso.
2. Instala `morseprende-etapa2.apk`.
3. A partir de ahora, cada versión nueva se instalará **encima** sin perder el progreso.

## Qué probar (marca cada punto)

### El Faro (pantalla principal)
- [ ] Se abre el mapa del capítulo 1 con 8 misiones; solo «La primera luz» está abierta y tiene un
      anillo coral.
- [ ] Abajo: Biblioteca (con un número de fichas nuevas), Traductor y Ajustes.

### Misiones
- [ ] «La primera luz»: lee el cuaderno de bitácora, escucha S y O, responde, transmite y descifra
      el mensaje final «SOS». Al terminar ves de 1 a 3 destellos (estrellas).
- [ ] Al volver al faro, la misión 2 está abierta y el haz del faro brilla un poco más.
- [ ] Repite una misión sacando peor nota: se conservan tus mejores estrellas.
- [ ] En el mensaje final, falla dos veces: aparece una pista; falla dos más: aparece el Morse.
- [ ] Las respuestas en minúsculas o con tildes cuentan como correctas.

### Manipulador
- [ ] **Un botón** (por defecto): toques cortos = punto, pulsación larga = raya. Suena mientras
      pulsas. ¿Notas retraso entre tu dedo y el pitido? (Apunta si es molesto.)
- [ ] Si vas despacio, el manipulador se adapta a tu ritmo y no corta la letra a medias.
- [ ] **Ajustes → Manipulador → Dos botones**: pulsa Punto/Raya y «Siguiente letra».
- [ ] «Borrar» quita lo último.

### Salir y volver
- [ ] Sal de una misión a medias (flecha atrás o botón de inicio): no se queda ningún pitido
      sonando y la misión no se marca como hecha.
- [ ] Cierra la app del todo y ábrela: tu progreso sigue ahí.

### Biblioteca
- [ ] Hay 3 fichas abiertas desde el principio y el resto se desbloquean con misiones.
- [ ] **Lee las fichas y dime si algo te parece raro o mejorable** (las fuentes están en
      `docs/biblioteca/fuentes.md`).

### General
- [ ] Modo avión: todo funciona igual.
- [ ] Si algo falla, anota qué hacías, qué esperabas y qué pasó (una captura ayuda mucho).
